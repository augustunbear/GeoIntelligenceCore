# ORS routing adapter

`OrsRoutingProvider` supplies walking (`foot-walking`), cycling (`cycling-regular`) and driving (`driving-car`) routes and directed duration matrices. It uses `HttpGateway` and requires an explicit `ProviderConfig` for `ors` with endpoint `https://api.heigit.org/openrouteservice`, a nonempty `credential_handle`, enabled `route` / `travelmatrix` capability flags, matching `UsagePolicy.allowed_capabilities`, and `https://api.heigit.org` in `allowed_endpoints`. Provide the API key securely to the gateway as an `Authorization` header; the handle is only an activation marker and is never sent by this adapter. Set bounded call count, cost, deadline and response bytes through the gateway policy and budget. No credentials or public endpoint are enabled by default.

Route coordinates are WGS84 `[longitude, latitude]` in explicit origin to destination order. Request `distance_unit` is `m` by default or explicitly `km`; the adapter requires the response `metadata.query.units` to match and converts kilometers to meters. ORS durations are seconds. The GeoJSON LineString and summary are returned as route geometry and quantities. A missing unit or malformed response is `unknown`, never a guessed measurement. An empty feature list is `unavailable` with `no_route`, never a straight-line substitute.

A matrix concatenates ordered origins then ordered destinations into ORS `locations` and sends separate `sources` and `destinations` indices. Each duration row is an origin and each column is a destination. A null cell is `unavailable` with null duration; successes alongside null cells make the result `partial`. Directed travel may differ in reverse. Matrix duration values are seconds; distance matrices are outside this adapter.

The ordinary ORS graph requests here do not represent timed traffic, transit schedules or arrival constraints. Requests with a time or `arrive_by` return `unsupported` before network use. Real road conditions, live coverage and provider graph vintage are not guaranteed. The optional live test remains skipped until current ORS terms, quota, output attribution/rights and permitted use are verified. Mock tests exercise the adapter without an external service.
