## Independent review and fixes

A fresh reviewer reproduced two P2 findings:

1. An unrelated selected null-data topic could borrow completeness from another
   topic's metric. Added a failing regression, then restricted the metrics-only
   evidence container to one exactly matching selected topic. Multiple/mixed null
   topics now return partial without a payload.
2. A manual correction can cite evidence absent from the unchanged Place evidence
   IDs. Comparing such a snapshot would omit its confirmation basis. Added a
   failing regression and made corrections/originals and derived comparison
   payloads explicitly unsupported until typed history semantics exist.

Both fixes are covered by RED-to-GREEN regressions. Other hardening tests reject
inconsistent Change shapes, foreign topic contexts and untrusted failure-context
leakage. The reviewer confirmed ordinary Snapshot JSON round-trip works.

A separate review of the published draft reproduced two more P2 fail-open cases:
the production `unknown` coverage marker could pass the nonempty gate and imply
a source record was missing, and a per-record/metric evidence-method switch was
hidden by an unchanged topic-wide method set. `complete:<coverage-ref>` is now
required as an explicit source-query completeness attestation; all other coverage
values return `partial` without changes. Shared records and metrics now compare
their individually resolved source methods before factual differences are emitted.
Both issues were reproduced in failing tests, then corrected. This attestation
does not prove real-world coverage; no current provider issues it automatically.

## Scope decisions and remaining acceptance

- The return sequence is an immutable tuple, JSON array on serialization, rather
  than a list generic that conflicts with the repository's frozen collections.
  Existing public models and root exports remain unchanged.
- Changed conditions suppress all record deltas conservatively. Unknown inputs
  return no payload. This can defer useful comparisons but avoids false changes.
- Human confirmation/relocation history is deferred, not declared completed.
  Source missing/added/updated facts never establish closure, movement or reality.
- WatchSpec only describes topics/conditions. No scheduler or notifications exist.
- Legal real-snapshot pair, real coverage/performance, consumer acceptance,
  source activation and complete E02 verification remain pending.
