# GeoIntelligenceCore P01–P02, P04–P05

Installable offline Python package. P01 confirms a manual point or explicitly selected candidate with provenance and versioned location identity. P02 resolves versioned profile/template defaults and explicit parameters under a hard usage policy, checks selected capabilities without calling providers, and defines immutable result shapes and JSON schemas.

P04 supplies bounded provider access and P05 supplies a configurable Photon candidate resolver. Geometry, other provider adapters, execution of analysis, live data and production activation remain separate steps. A capability registered as configured is only a preflight declaration. No endpoint or credentials are bundled.
